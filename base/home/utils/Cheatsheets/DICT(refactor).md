## Using modifiers
Super/Windows key = Super-
Ctrl = C-
Alt/Meta = M-
Shift = S-
Leader (Vim/WM specific) = <leader>

### Combination rules
- Join modifiers with - (dash)
- Separate alternatives with /
- group related with + when order doesn’t matter
    Use - for normal cases (Super-h, C-s)
    Use + only when two or more modifiers must be held together (C+M-x)

### Examples
    C-M-x = Ctrl+Alt+x
    Super-<Tab> = Super+Tab
    S-<Print> = Shift+PrintScreen
    C-x C-s = press Ctrl+x, release, then Ctrl+s (sequence)
    C+M-x = press Ctrl and Alt together, then x (combo)

# Key Notation
* Use angle brackets (<>) for special(non-alphanumeric) keys

<CMD> or <Super> Super/System/Windows key
<Esc> = Esc
<A> or <M> = Alt
<S> or Capital letter = Shift
<C> or ^ = Ctrl
<Enter> or <CR> = Enter
<BS> = Backspace
